# 观察、动作和训练协议

环境在独立 CA-VAL-AIM 进程中运行，不控制桌面鼠标键盘。后续外设后端需要单独实现，不能把模拟器的世界状态接口直接当作真实客户端感知。

## 观察

`uint8[90,160,3]` RGB，范围 0–255。截图在动作后的渲染帧完成时读取。PPO 堆叠最近 4 帧，模型输入不拼接坐标、目标距离、血量或弹药真值。

当前导航阶段关闭上游教练 HUD，也没有声音输入。`info` 中的 `position`、`distance_to_goal`、`hp`、`ammo` 只服务奖励、诊断和验证；自定义策略不要将它们当输入，除非明确另开“状态观测”的实验。

## 动作

Gymnasium `MultiDiscrete([3,3,3,5,3,2,2,2])`，每次传入 8 个整数：

| 索引 | 含义 | 可选值 |
| --- | --- | --- |
| 0 | 前后 | 0 无，1 前，2 后 |
| 1 | 左右 | 0 无，1 左，2 右 |
| 2 | 姿态 | 0 跑，1 走，2 蹲 |
| 3 | 水平转角 | 0–4 对应 -15、-5、0、5、15 度 |
| 4 | 垂直转角 | 0–2 对应 -5、0、5 度 |
| 5 | 跳跃 | 0 松开，1 按住 |
| 6 | 射击 | 0 松开，1 按住 |
| 7 | 换弹 | 0 无，1 请求换弹 |

无动作是 `[0,0,0,2,1,0,0,0]`，**不是全 0**。转角是一次 step 的总量，均匀分到默认 6 个模拟子步。默认 10 次决策/模拟秒；壁钟采样速度取决于渲染和训练性能。

## 场景和奖励

配置使用上游地图的米制坐标，Y 轴向上；地图的偏移与缩放由上游加载器处理。默认 Lotus 起点附近的短路线带少量初始朝向扰动，目标有可见青色标记。

每步奖励：`0.5 × (上一步目标距离 - 当前目标距离) - 0.01`；进入 0.8 米目标半径额外 +5；死亡或跌落额外 -1。成功、死亡、跌落返回 `terminated`；达到 300 步返回 `truncated`。结束后必须 reset。

reset 重置角色、弹药、时钟和随机种子，并检查出生点是否因碰撞发生明显搬移。跨平台画面不保证逐像素完全一致。

此奖励用于短距离环境验证。更复杂地图需要设计可达路线、分段目标/课程，避免欧氏距离奖励诱导撞墙。取消目标标记后，需要另行提供目标信息或固定任务上下文。

## 进程间接口

Python 启动 Godot 后，从该实例独立目录的 `ready.json` 获取端口。桥只监听 `127.0.0.1`，版本 `protocol=1`，使用 UTF-8 每行一个 JSON；请求必须有递增 `id`。

```json
{"id":1,"command":"reset","seed":42}
{"id":2,"command":"step","action":[1,0,0,2,1,0,0,0]}
{"id":3,"command":"close"}
```

响应包含同一个 id、ok、protocol、width、height、RGB 原始字节的 Base64、reward、terminated、truncated 和 info。错误响应包含 error。客户端检查帧尺寸和字节数；超时或协议失败会停止该回合，不悄悄生成虚假帧。

只适合同一受信任主机上的研究进程。没有远程鉴权，也不应开放为公网服务。Python 正常关闭时只终止自己启动的引擎；附加到已有端口时不拥有引擎进程。
