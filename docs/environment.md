# 观察、动作和训练协议

环境在独立 CA-VAL-AIM 进程中运行，不控制桌面鼠标键盘。后续外设后端需要单独实现，不能把模拟器的世界状态接口直接当作真实客户端感知。

## 观察

正式任务为 `uint8[144,256,3]` RGB；旧导航自检为 `[90,160,3]`。截图在动作后的渲染帧完成时读取。BC/PPO 都堆叠最近 4 帧，回合开始以零帧补齐；模型输入不拼接坐标、距离、血量或弹药真值。

关闭上游教练 HUD，正式任务添加仅有 HP、护盾、弹药和换弹信息的 HUD；没有声音输入。`info` 中的真值只服务奖励、诊断和验证，不进入玩家信息条件下的运行策略。

## 动作

正式任务为 `MultiDiscrete([3,3,3,9,9,2,2,2])`，由场景的视角档位决定，每次传入 8 个整数：

| 索引 | 含义 | 可选值 |
| --- | --- | --- |
| 0 | 前后 | 0 无，1 前，2 后 |
| 1 | 左右 | 0 无，1 左，2 右 |
| 2 | 姿态 | 0 跑，1 走，2 蹲 |
| 3 | 水平转角 | 0–8 对应 -12、-4、-1、-0.25、0、0.25、1、4、12 度；正值向右 |
| 4 | 垂直转角 | 与水平同档位；正值抬头 |
| 5 | 跳跃 | 0 松开，1 按住 |
| 6 | 射击 | 0 松开，1 按住 |
| 7 | 换弹 | 0 无，1 请求换弹 |

正式任务无动作是 `[0,0,0,4,4,0,0,0]`，**不是全 0**。请使用 `env.noop`。转角是在一个目标动作周期内的总量，均匀分到 3 个 60 Hz 子步，目标 20 次决策/秒。实时模式按同样角速度保持最近动作，直到新动作到达或过期。

旧导航自检仍是 `[3,3,3,5,3,2,2,2]`，无动作 `[0,0,0,2,1,0,0,0]`，6 子步/动作。模型同名 `.json` 保存观察、任务、动作档位和时间契约；不兼容时拒绝加载，不能只检查动作向量长度。

## 场景和奖励

配置使用上游地图米制坐标，Y 轴向上。正式任务为 Lotus A Root → A 入口的多个路线检查点，不显示额外路标；固定任务上下文由所选模型/课程约定。敌人采用上游 Bot、射击命中与伤害，首版固定位置，可设置是否回击与生成概率。

移动交战初始奖励：每米新的最佳检查点距离改善 +0.05；每个新检查点 +0.3；每次有效命中 +0.1、击杀 +2；每次射击 -0.005，移动中射击额外 -0.01；每动作周期 -0.002；完成任务 +5，死亡/跌落 -2。没有按键次数奖励、站立奖励或朝向隐藏敌人的奖励。进展只按新的最佳距离累计，不能往返刷分；检查点到达奖励与该步进展不重复发放。

成功要求经过全部检查点、击杀本回合生成的敌人，并处于最终目的地半径内。只击杀不成功；空回合只需完成路线。默认 1200 步为 60 模拟秒。成功/死亡/跌落返回 `terminated`，超时返回 `truncated`，结束后必须 reset。权重是待学习曲线检验的工程初值。

导航自检沿用 `0.5 × 距离改善 - 0.01`、成功 +5；0.2 版统一失败扣分为 -2。它只服务回归检查。

reset 重置角色、相机、弹药、时钟、随机种子、敌人、任务计数和临时效果，并检查出生点是否因碰撞明显搬移。Bot 动画/命中形状随受控模拟时钟更新。真实备用弹药会消耗，训练入口关闭上游的无限备用弹药便利。跨平台画面不保证逐像素完全一致。

更多路线需验证每段可达性，不能靠欧氏距离穿墙规划。当前无通用寻路教师、地图坐标输入或自动恢复控制器；模型错误进入开发纠错流程。

## 时钟与分组

lockstep 等待客户端指令；realtime 从第一条动作开始按独立墙钟推进。动作 250 ms 未更新会释放；渲染过慢导致的时间损失单独累计。时序指标见[使用手册](stage1-guide.md)。

PPO reset 只使用 `[0,100000)` 训练种子。人工训练、validation、dev、test 分别使用从 0、100000、200000、300000 开始的种子区间；CLI `--seed` 是区间内索引。`reset(options={"engine_seed": n})` 可明确重放原题。开发题补课允许进入训练，但不成为正式测试成绩。

场景变体或种子留出不等于跨地图泛化。题库保存场景和种子，从回合起点重做；不支持任意时刻快照。

## 进程间接口

Python 启动 Godot 后，从实例独立目录的 `ready.json` 获取端口。桥只监听 `127.0.0.1`，`protocol=1`、`revision=2`，使用 UTF-8 每行一个 JSON；请求必须有递增 `id`。

```json
{"id":1,"command":"reset","seed":42}
{"id":2,"command":"step","action":[1,0,0,4,4,0,0,0]}
{"id":3,"command":"close"}
```

响应包含同一个 id、ok、protocol、width、height、RGB 原始字节的 Base64、reward、terminated、truncated 和 info。错误响应包含 error。客户端检查帧尺寸和字节数；超时或协议失败会停止该回合，不悄悄生成虚假帧。

只适合同一受信任主机上的研究进程。没有远程鉴权，也不应开放为公网服务。Python 正常关闭时只终止自己启动的引擎；附加到已有端口时不拥有引擎进程。
