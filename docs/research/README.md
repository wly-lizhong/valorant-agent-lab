## 状态与证据约定

- **已实现 / 已验证**：须有仓库代码或明确运行记录；脚本控制成功不能算模型学会。
- **采用的方向**：项目已经选择的路线，具体模块仍可能待开发。
- **候选参数 / 拟定门槛**：实验起点，不是性能承诺；例如图像尺寸、决策频率、成功率目标。
- **参考结果**：原作者在其任务、数据、输入和硬件上的报告，不自动转移到本项目。
- **未验证**：未运行参考项目或未取得正文的内容，保留范围说明。

文档中的教程练习与训练设计是项目综合提出的方案，不冒充原作者实验。视频只读到元数据或简介的会明确标注；本轮未取得可靠的视频全文字幕或 B 站评论正文。公开帖子只涵盖实际读取的正文和选定回复。

## 文档来源与维护

教学研究基于维护者提供的资料清单以及补充检索；技术研究优先引用论文、作者项目页、官方仓库及文档。引用保留原始链接，不发布私人对话、工作机路径、访问凭据或完整转载作品。论文、代码、模型、数据和地图分别保留各自来源及使用条件，引用不意味着已经集成为项目依赖。

当实现一个工作包时，同时更新状态表、配置版本和对应验证记录。改变动作协议、画面预处理或奖励语义时，更新数据版本，不能默默沿用旧样本。
