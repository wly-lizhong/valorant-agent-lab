# 真人示范录制操作规范

适用版本：`windows-recorder` 分支、CA-VAL-AIM v2.15.0、本机原生录制。更新日期：2026-11-28。

这份文档回答“每门课应该怎么操作、什么值得保留、什么时候重录”。安装与文件传输见 [Windows 采集指南](windows-capture.md)，本轮具体编号见 [12 条补录清单](next-capture-batch.md)。**本轮只补“停稳射击”和“补录 · 近距有敌”各 6 条；其他课程的说明留作以后使用，不要求现在全部重录。**

## 先明确：停稳射击是否必须先移动

**本批“停稳射击”的标准示范要求：实际移动 → 松开移动键、停稳 → 修正瞄准并射击 → 确认击杀 → 继续到终点。** 从出生点一直不动、先把敌人打完再走，即使游戏判成功，也没有演示“移动后停稳射击”，不作为这批课程的合格主样本。

这项要求属于本课程的采集规范。**“近距有敌”开局已看见近处敌人时，可以直接停在原位瞄准射击；“组合交战”也应按威胁处理，不能为了凑一个 W 动作而忽略已经出现的敌人。** 这些都是模型需要学会的正确行为，不能全部改成固定起手式。

这里的“先移动”指人物沿可通行路线产生实际位移，不是碰一下 W、对着墙按 W，或者故意冲过敌人再回头。移动时可以观察和预瞄，不必等停下才动鼠标；要求停稳的是**开枪时的身体移动**。

本次只整理人工操作与审核标准，**没有新增自动判定“首枪前必须移动”的代码，也没有改游戏成功条件**。旧示范和已训练模型保留，不因新规范自动判废或改标签。

## 一页速查

| 课程 | 当前场景 | 标准操作顺序 | 必须避免 |
| --- | --- | --- | --- |
| [路线行走](#路线行走) | 完整短路线、无敌人 | 看通道 → 移动并转弯 → 到终点 | 空枪、乱跳、绕远、持续撞墙 |
| [停稳射击](#停稳射击) | 完整短路线、1 个不回击的敌人 | 先实际移动 → 停稳 → 瞄准射击 → 确认击杀 → 继续走 | 从出生点原地打完再走、边跑边扫、漏杀就离开 |
| [补录 · 近距有敌](#补录--近距有敌) | 中段起步、约 3 米处有敌人、不回击 | 看清敌人 → 必要时调位置 → 停稳瞄准击杀 → 继续走 | 为凑 W 冲过敌人、杀后不走 |
| [补录 · 近距无人](#补录--近距无人) | 与近距有敌相同起点、无敌人 | 观察 → 沿通道前进 → 到终点 | 对记住的敌人位置开枪、原地等敌人 |
| [换弹与前进](#换弹与前进) | 弹匣初始为 0、1 个不回击的敌人 | 看弹药 → 换弹完成 → 移动接敌 → 停稳射击 → 到终点 | 空扣扳机、反复按 R、没换完就当作能射击 |
| [调整视角](#调整视角) | 初始俯仰明显偏离正常、无敌人 | 放开移动键 → 恢复视角 → 看清通道 → 导航 | 看着天或地长按 W、大幅乱甩、空枪 |
| [组合交战](#组合交战) | 可能有敌人；有敌人时会回击 | 看画面判断 → 无人就走／有敌停稳交战 → 必要时换弹 → 到终点 | 每局固定开枪、固定换弹、为凑动作忽略威胁 |

当前七门课共用同一段 Lotus A Root → A 入口训练区路线，近距课从中段开始。绿色终点圈画在**旁边的路线引导窗口**，不是游戏世界里必然可见的立柱；终点不是整个 A Site。蓝点仅作路线参考，不要求逐个踩中。

当前正式课程的时限都是约 **60 秒模拟时间**。有敌人的课程必须击杀本回合生成的目标并到达终点；无敌课程到达终点即可。打死敌人不会单独结束课程，到了终点但敌人还活着也不会结束。

## 开始前的统一准备

1. 关闭旧游戏和选关窗口，更新 `windows-recorder` 后运行 `start_windows.cmd`。使用项目的中文示范台。
2. 逐项核对“课程／训练示范或独立验证／变化编号”。本轮 12 条全选 **训练示范**；不要沿用上次下拉框里的用途。
3. 等地图与路线引导加载好，先读懂本关任务。需要熟悉路线时可以先试跑并放弃，再重新加载正式录制；不要把不熟悉控件的试跑作为成功示范提交。
4. 正式段从按 **Enter** 后开始。准备好再开始，避免开始后长时间看说明、聊天或等人；也不要在录制开始前就把本应演示的瞄准或恢复动作做完。
5. 尽量使用默认角色、枪械、分辨率和项目设置。手感异常先排查，不修改移速、弹道或质量门槛来适应错误。
6. 操作期间把焦点留在游戏窗口。不点击旁边引导、不 Alt+Tab、不打开菜单；切换窗口会停止本段。

### 按键怎么用

| 按键 | 用途 | 本阶段规范 |
| --- | --- | --- |
| W／A／S／D | 前后左右移动 | 正常沿通道走；需要停稳时全部松开 |
| 鼠标移动 | 水平／垂直转向、瞄准 | 连贯调整，允许小幅修正，不故意来回摇摆 |
| 鼠标左键 | 射击 | 确认可见目标后单发或短连射，观察反馈再修正 |
| R | 换弹 | 按一次后等待完成；不要频繁按住或重复触发 |
| 左 Shift | 静步 | 确有必要时使用，不为凑动作刻意全程静步 |
| 左 Ctrl | 蹲伏 | 本批以站立射击为主，暂不要求蹲射套路 |
| 空格 | 跳跃 | 当前路线不要求跳跃，不随意增加跳射、连跳 |
| Enter | 开始；成功后确认保存 | 两个阶段分别使用，不是按一下就已经保存 |
| Esc | 放弃并返回 | 不等于保存成功示范 |

当前录制动作没有右键开镜、换枪或角色技能接口；不要加入这些操作并期待模型学到。暂不录反向急停技巧、固定压枪宏或复杂身法。

## 停稳、瞄准和击杀的共同要求

**停稳：** 松开 W、A、S、D，让人物停止平移再开火。只松 W、仍按着 A 或 D，不算停稳。停稳时仍然可以用鼠标修正准星。不要求反向按键急停，也不规定每次固定等多少毫秒；观察画面中的位移是否停止，不要按秒表表演。

**瞄准：** 以当时游戏画面中的敌人为依据，把准星放到头部或上半身；这批允许稳定的身体命中，不要求每枪爆头。移动中可以预瞄，停下后继续精调。不要只凭记住的编号、墙上位置或固定鼠标距离盲打。

**射击：** 优先单发或短连射，没命中就松开左键、修正准星，再射击。不要持续扫空、一直往同一个错误方向开枪。轻微打空后自然调整是有用示范，不必追求毫无误差。

**确认击杀：** 看敌人倒地、死亡动画等可见反馈。开过枪、弹药变少、准星掠过敌人，甚至敌人暂时被墙挡住，都不能证明击杀。不要凭固定发数决定“肯定死了”；也不必等尸体完全消失才移动。现有简化 HUD 主要显示血量、护盾、弹药和换弹状态，不要等待不存在的专用击杀计数提示；训练侧会另核对实际命中和击杀。

**继续行动：** 确认击杀后松开左键，恢复面向通道并走向终点。不要站在尸体旁长时间等待，不要边走边向已经空掉的位置补枪。

## 每门课程的完整流程

### 路线行走

目的：提供清楚的移动、转弯和到达目的地示范，也提供“没有敌人就不开枪”的样本。

1. Enter 后看清通道方向，正常前进。
2. 接近转角时用鼠标转向，必要时配合短暂侧移；走通道自然路线即可。
3. 准星保持在便于观察前方的高度，不长期盯脚下或天空。
4. 按旁边示意图到绿色终点圈，出现“任务完成”后确认保存。

**可以保留：** 转弯时短暂停一下、轻微走偏后立即修正。**应重录：** 开空枪取乐、原地转圈、长时间找路、反复顶墙。不要为了增加动作多样性而故意制造这些错误。

### 停稳射击

目的：重点补齐“已经移动起来后，能停下来处理目标，再继续导航”。这批按下面顺序录。

1. Enter 后先沿通道**实际移动一小段**，保持观察前方。移动中可以转向、预瞄。
2. 当前关卡的敌人不回击；即使开局已经看见远处敌人，也先完成这段可控移动，再停稳处理。不要冲到敌人身后，不要求走到某一个隐藏坐标或固定蓝点。
3. 全部松开移动键，停稳，修正准星到可见敌人身上。
4. 点射或短连射；打空时自然调整，直到看见击杀反馈。
5. 松开左键，重新沿通道前进，到绿色终点并确认保存。

**合格的关键片段：** 首次射击前确有前进位移；开枪时停止平移；瞄准修正与画面对应；击杀后重新移动。不是仅仅让记录里出现一次 W。

**应重录：** 出生点原地把敌人打完才开始移动；碰一下 W 但没有位移；一边持续跑一边扫射；到终点时敌人仍活着。若场景表现异常，根本无法安全完成预期移动，先放弃并报告课程／编号，不要硬凑动作或自行更换配置。

这是对**本门课程、本批示范**的要求，不能推广成“任何看到敌人的场合都必须先走再打”。近距和组合课按各自规则处理。

### 补录 · 近距有敌

目的：学会处理眼前已经出现的目标，并在击杀后继续行走。本关从路线中段开始，敌人约在 3 米处且不回击。

1. Enter 后先看清目标。若已经可见，保持停稳、直接调整准星并射击即可，**不强制先按 W**。
2. 若视角偏离目标，先转向找到目标；确需调整位置时可作短暂合理移动，射击前再停稳。
3. 命中不够就修正，确认击杀后松开左键。
4. 顺着当前通道继续到绿色终点，不用回头补走 A Root 或前面的蓝点。

**可以保留：** 开局原地瞄准击杀；必要的小步调整后停稳击杀。**应重录：** 为了凑 W 冲到敌人身后；只盯固定墙点盲射；击杀后不继续走。当前 6 条不强行规定哪几条必须先移动，按实际画面决定。

历史第二批曾专门要求“先短按 W”，用于补移动中接敌的覆盖；它不是本轮近距课的统一起手规范。旧数据保留，不回改标签。

### 补录 · 近距无人

目的：让模型看到与近距交战相似的通道，但学会在无目标时继续行走、不乱开枪。

1. Enter 后观察眼前通道，确认当前可见区域没有目标。
2. 自然向前走，随转角调整视线。观察可以和行走同时进行，不必原地长时间找一个不存在的敌人。
3. 不开枪、不刻意换弹，到终点后保存。

**应重录：** 因为记得有敌课的出生位置就先打一梭子；机械复制有敌课的停枪节奏；为了“让数据有动作”而跳跃、转圈。

### 换弹与前进

目的：从可见弹药状态触发换弹，换完以后继续完成移动与交战。本关初始弹匣为 0，敌人不回击。

1. Enter 后看 HUD 弹药，按一次 R，随后松开。
2. 等待换弹动作结束、`RELOADING` 状态消失并确认弹匣有子弹，再继续。本批先在原位完成这次换弹，减少同时操作的干扰。
3. 沿路线移动接敌，停稳瞄准，击杀后继续到终点。
4. 后续只有确实需要时再换弹，不能打每一枪都按 R。

**应重录：** 开局长时间扣扳机不处理空弹匣；连续反复按 R；换完弹就站着不走；漏掉敌人只顾跑终点。无需先空开几枪“证明没子弹”，HUD 已提供信息。

### 调整视角

目的：从不正常的观察角度恢复正常视线，再导航。本关初始俯仰偏转较大，没有敌人。

1. Enter 后先保持不移动，不开枪。
2. 用鼠标把视角调回能正常看见通道、地平和前方的位置，再修正水平方向。根据画面判断方向，不照固定鼠标距离甩动。
3. 看清可走的通道后才开始前进，按路线到终点。

**可以保留：** 一次小幅过头后自然调回。**应重录：** 视角还朝天或朝地就一直按 W；连续左右摆头找不到方向；恢复后又故意制造多次失控。

本课程从预设开局恢复视角，**不是**从模型卡死的中途存档恢复。

### 组合交战

目的：按画面和弹药决定何时走、停、打、换弹。当前配置每局可能生成 0 或 1 个敌人，生成时会回击；不要根据课程名猜这局一定有敌人。

1. Enter 后观察前方。可见区域无人就沿通道前进，转角时继续观察。
2. 看到敌人时处理威胁，停稳、瞄准、射击；若开局就出现可见威胁，可以直接应对，不为了套顺序先向前冲。
3. 需要换弹时再按 R；仍有弹药且能完成击杀，不要求人为加一次换弹动作。
4. 确认目标击杀后继续走；本局没有敌人时，直接完成路线，不寻找不存在的交战。
5. 以游戏“任务完成”为结束依据。

**可以保留：** 受到少量伤害但有合理应对并完成任务。**应重录：** 为了凑动作而送伤害；没看到目标就预先向固定点开枪；无敌人仍整套停枪换弹；敌人未死就离开。

### 云端下发的纠错题

先读题目说明，再套用对应课程的基本流程。当前题包从原回合起点和种子重做，尚不能直接恢复到模型撞墙的那一帧。

纠错题固定用于训练，不要手工把它改成独立验证。也不要先故意复现长时间撞墙、绕圈或乱甩再“救回来”，把整段坏操作当正面示范；需要专门采集失败状态接管时，应另外安排采集机制与标记。

## 哪些情况保留，哪些需要重录

| 情况 | 处理 |
| --- | --- |
| 偶发打空，随后根据画面修正并击杀 | 可以保留，修正过程有价值 |
| 转角轻微偏离，马上纠正后顺畅继续 | 可以保留 |
| 正常停稳、瞄准、观察、换弹等待 | 保留，不删掉这些必要的“没有移动”片段 |
| 近距课开局已有目标，直接原地瞄准击杀再走 | 合格，不以没有先按 W 判废 |
| 本批停稳射击从头到尾原地打完，再开始走 | 不满足该课采集要求，重新录同编号 |
| 明显跑射、长时间扫空、反复对空地开枪 | 放弃重录 |
| 长时间发呆、聊天、反复撞墙、迷路绕圈 | 放弃重录，不为凑数量确认保存 |
| 切走窗口、Esc、死亡、超时、严重卡顿或保存失败 | 按界面提示处理；保留日志后重新录，不改成功标签 |
| 偶发短暂停顿后系统恢复，最终没有质量问题且操作连贯 | 不必仅因标题显示“恢复”就判废；频繁发生应先排查设备 |
| 课程、训练／验证用途或编号选错 | 先别上传；记录文件 ID 和选错内容，交给维护者核查，不直接改 JSON |

不用追求每条像复制粘贴一样。速度、停稳时机、修正幅度可以自然变化，但不要故意乱按、拖延或制造错误来“增加多样性”。目前 12 条只是最小补充批次，不代表足够训练出成熟模型。

## 完成、保存、上传的顺序

1. 完成击杀和路线要求后，等屏幕明确出现 **“任务完成！”**。
2. 回想本段是否符合该课程规范。符合才按 **Enter**；即使游戏成功，但本段明显跑射或流程不符合要求，也可以按 **Esc** 放弃后重录。
3. 等回到选关器并看到 **“示范已保存，可上传供云端训练”**。仅看到游戏成功还不等于文件已确认保存。
4. 同编号重录不覆盖旧记录，会生成新的 `episode-…` 目录。不要靠反复重录来自动替换误收的旧样本。
5. 本轮 12 条录好后，点一次 **“上传成功示范”**。按钮打包本地所有符合程序条件的成功记录，不是只上传最新一条，也不是只上传这次清单的编号；云端按 ID 与哈希去重。
6. 如果发现错误示范已经确认保存，**先暂停上传并报告对应记录**；上传器不会自动理解本文的动作规范并替你筛掉它。若已经上传，也报告 ID／课程／编号，保留原件，由维护者记录排除，不手动删除或篡改标签。

转换后的示范在 `runs/demonstrations-v215/episode-…/`，其中 `episode.json` 记录课程、种子、分组与质量信息，NPZ 保存画面和动作；原始记录在 `runs/native/capture-…/`。它们不是普通 MP4。记录 ID 可从新生成的文件夹名确认，不必修改里面的内容。

## 训练、验证和审核边界

- 本轮全部选训练示范。已有独立验证保持独立，不把它换个标签加进训练；最终验收数据也不用于补录或调参。
- 不在同一段录制中途切换课程／分组／编号。选错后需要重新录，不能用改元数据来补救。
- **程序通过**检查任务成功、确认保存、时序、画面动作对齐和质量问题；**人工合格**还要检查本文规定的操作过程。两者不能混为一谈。
- 当前程序不会因为“站在出生点先打完”“空场景偶发乱射”“长时间无效走动”就必然拒收。如果最终仍通关，某些坏示范可能显示可上传；录制者要在确认前把关，维护者再查轨迹。
- 后续可检查首枪前实际位移、射击时移动、命中／击杀、击杀后的继续移动、空场景开枪和卡住片段。这些是审核维度，不宣称已全部实现自动筛选。
- 模型训练只接收玩家画面。教师路线引导在独立窗口，不进入游戏 RGB；不能把后台敌人坐标作为操作提示或模型输入。
